# 💼 Binoy Premium Portfolio

A modern, responsive, and interactive personal portfolio website built with **Python Flask, HTML, CSS, and JavaScript**.

The portfolio showcases my skills, projects, certifications, resume, and professional journey through a clean and premium user interface.

## ✨ Features

- 🎨 Modern & premium UI design
- 📱 Fully responsive layout
- 🧑‍💻 About Me section
- 🛠️ Skills & technologies showcase
- 🚀 Projects section
- 📜 Certifications section
- 📄 Resume section
- 📬 Contact form
- 🖼️ Certificate image lightbox
- ⚡ Interactive JavaScript elements
- 🐍 Flask backend
- 🗄️ SQLite database integration
